# Claude certification prep

Self-made practice tooling for Anthropic's Claude certification exams, written by
[Arshdeep Singh](https://github.com/arshkharbanda2010).

| Exam | Folder | Status |
|---|---|---|
| Claude Certified Developer – Foundations (CCDV-F) | [`developer-foundations/`](developer-foundations/) | Available |

## Principles

- **Your guide, your source of truth.** The tools work from the official exam guide you
  download yourself. Nothing here replaces it.
- **No live exam content.** The exams are confidential and covered by a non-disclosure
  agreement. This repo contains only original practice material and study aids.
- **Explain the why.** Every practice answer comes with the reasoning and the trap it avoids.
